## “不限流量”到底不限什么？

答案就一句话：不限的是流量，限的是带宽。这类套餐（行业里叫unmetered）不统计你用了多少GB，端口速度封顶才是它真正的边界。所以挑不限流量VPS，本质是在挑带宽，价格差也主要差在带宽上。

真实流量上限可以自己算：带宽 × 时间。1Mbps跑满24小时，一天约10.8GB，一个月约320GB。各档位换算如下：

- 1Mbps：约320GB/月
- 2Mbps：约640GB/月
- 3Mbps：约950GB/月
- 5Mbps：约1.6TB/月
- 10Mbps：约3.2TB/月
- 30Mbps：约9.5TB/月

这个换算表很实用。搬瓦工香港入门款500GB/月的流量配额，和1Mbps不限流量款的实际上限在同一量级——前者卖的是1Gbps峰值速度和优质线路，后者卖的是“永远不用盯着流量表”。两种商品，别拿错需求去对价。
